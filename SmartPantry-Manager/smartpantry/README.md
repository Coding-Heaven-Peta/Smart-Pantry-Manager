## Smart Pantry Manager

A Java Android application that suggests recipes based **strictly** on the ingredients a
user already has at home, in order to cut food waste.

## Run the app Natively on your android device (What i did)

Install **`SmartPantry-debug.apk`** on an Android 7.0+ phone:

* Copy it to the phone and tap it (allow "install unknown apps"), or
* `adb install -r SmartPantry-debug.apk`

The launcher shows **Smart Pantry**. Then go **Settings ▸ Load demo pantry** to fill the
pantry instantly.

## Want to run the code using an emulator in Android studio

Android Studio → **File ▸ Open** → choose the **`smartpantry`** folder (the one with
`settings.gradle`). Wait for the Gradle sync, start an emulator, press **Run ▶**.

Full instructions and troubleshooting: `smartpantry/docs/SETUP_AND_DEMO.md`.
